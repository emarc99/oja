# Òjà

Built for the **MLH Solana Hackathon** (Nov 6–8, 2026).

Òjà (Yoruba for "market") is a Solana Pay checkout for Nigerian traders. Every sale becomes an on-chain receipt the trader owns, that sales history qualifies them for a working-capital advance, and the advance repays itself from a share of each later sale, split atomically by a Solana program.

Work in progress; full write-up coming.

## Layout

- `programs/oja`: the Anchor program (Rust)
- `app`: the web app (Next.js)
